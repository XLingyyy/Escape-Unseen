# Escape Unseen

A 2.5D puzzle-platformer made for the **2026 Epic AI MegaJam** (theme: *Director's Cut*), built in **Unreal Engine 5.8.4**.

> Direct your own prison break. A guard checks every shot under the same lamp. Hide your props in the shadows, get each shot approved, then step into the scene you built.

## Status

The jam has started, but development hasn't yet. This repository only holds the empty UE project (`EU/`). Gameplay, levels and assets will land here as they are built.

## Repository layout

| Path | Contents |
|---|---|
| `EU/` | Unreal Engine 5.8.4 project (`EU.uproject`, `Config/`, `Content/`) |

## Requirements

- Unreal Engine 5.8.4
- Windows 64-bit

## Tools

Development uses AI-assisted tools. These include Claude Code, connected to the Unreal Editor via the engine's experimental Unreal MCP plugin. Asset sources and AI use will be documented with the submission.
